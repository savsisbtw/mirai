# Mirai

Аниме-плеер для винды. Весь каталог в одном месте, без деления на источники: AniLiberty и Yummy склеены, а озвучку выбираешь уже в тайтле.

- бек на Go, каталог и поиск живут в памяти, поэтому быстро
- клиент на Tauri, своё окно вместо системной рамки
- винда 11, на 10 тоже запускается, но могут быть баги
- телефоны (iOS и Android) потом, план в [docs/MOBILE_PLAN.md](docs/MOBILE_PLAN.md)

## Как устроено

```
server/    Go-бек: обходит AniLiberty и Yummy, склеивает дубли, отдаёт /v1/*
desktop/   Tauri-клиент, сам поднимает сервер у себя в фоне
docs/      контракт API и планы
```

Клиенты ходят только в наш сервер, подробности в [docs/API.md](docs/API.md).
