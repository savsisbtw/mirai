# Mirai

Аниме-плеер для винды. Весь каталог в одном месте, без деления на источники, а озвучку выбираешь уже в тайтле.

- быстрый поиск и каталог
- свой дизайн и своё окно вместо системной рамки
- винда 11, на 10 тоже запускается, но могут быть баги
- телефоны (iOS и Android) потом, план в [docs/MOBILE_PLAN.md](docs/MOBILE_PLAN.md)
